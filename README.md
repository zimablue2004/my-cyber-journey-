# Мой путь в кибербезопасность

## План обучения:
1.  **Основы сетей:** Модель OSI, TCP/IP, DNS, HTTP/HTTPS.
2.  **Операционные системы:** Linux (Ubuntu), Windows.
3.  **Языки программирования:** Python для автоматизации, Bash для скриптов.
4.  **Инструменты:** Nmap, Wireshark, Burp Suite.
5.  **Веб-безопасность:** OWASP Top 10, SQL-инъекции, XSS.
6.  **Практика:** Прохождение лабораторий на TryHackMe, Hack The Box.
