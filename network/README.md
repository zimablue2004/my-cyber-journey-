# Анализ сетевого трафика (Wireshark)

В ходе задания был произведен захват ICMP-трафика с помощью утилиты Wireshark во время выполнения команды `ping 8.8.8.8`. 
В строке фильтра был применен фильтр `icmp`.

## Какие слои модели OSI видны в захвате:

Если выбрать пакет `Echo (ping) request` и развернуть окно деталей пакета, видны следующие слои:

1. **Layer 2 (Канальный уровень / Data Link):**
   * Отображается как `Ethernet II`.
   * На этом уровне видны **MAC-адреса**: физический адрес сетевой карты отправителя (Source) и получателя (Destination, в данном случае — MAC-адрес Wi-Fi роутера).

2. **Layer 3 (Сетевой уровень / Network):**
   * Отображается как `Internet Protocol Version 4` (IPv4). Здесь видны логические **IP-адреса** отправителя (мой локальный IP) и получателя (8.8.8.8), а также время жизни пакета (TTL).
   * Также на сетевом уровне работает сам протокол `Internet Control Message Protocol` (ICMP), который отвечает за передачу служебных сообщений (в данном случае — запросов и ответов ping).

*Примечание: Транспортный уровень (Layer 4, TCP/UDP) в данном захвате отсутствует, так как протокол ICMP работает напрямую поверх IP и не использует порты.*
